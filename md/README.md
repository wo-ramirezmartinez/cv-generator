# Documentación de perfil profesional

Carpeta de fuente única para alimentar el generador de CV. Aquí vive la información **completa y contrastada**; los CV exportados son recortes orientados a cada postulación.

## Archivos

| Archivo | Uso |
|---------|-----|

| [certificaciones.md](./certificaciones.md) | Certificados (ej. React Udemy 2022) |

| [competencias-implicitas.md](./competencias-implicitas.md) | Git, npm, Agile, etc. razonables sin haberlos narrado |
| [experiencia/](./experiencia/) | Un archivo por empresa con detalle máximo |

## Cómo mantenerlo

1. Añade datos nuevos en el archivo de la **empresa** correspondiente (sección «Notas y variantes» si es un matiz de un CV viejo).
2. Actualiza **conocimientos-solidos.md** solo cuando una habilidad esté respaldada por trabajo real en al menos un rol.
3. Ajusta el **resumen** en `perfil-maestro.md` cuando cambie tu foco profesional (ej. más Arc XP, más full-stack).

## Fuentes fusionadas

Las experiencias actuales consolidan **tres versiones** de CV (misma trayectoria, distinto énfasis: plataforma editorial Arc XP, analítica/GTM y migraciones de datos, servicios Node.js y coberturas especiales).
